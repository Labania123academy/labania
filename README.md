# Labania — SmartLearn Academy

This is the first responsive homepage for Labania. It is a static website made with HTML, CSS and JavaScript.

## Preview on your computer
1. Extract the ZIP file.
2. Open the `labania_website` folder.
3. Double-click `index.html` to open it in a browser.

## Before publishing
- Replace `hello@labania.example` in `index.html` with an email address you control.
- Add real course descriptions and original learning resources.
- Do not upload copyrighted notes, textbooks or exam papers unless you have permission.
- Add a privacy notice and appropriate contact details before collecting information from visitors.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a new public repository named `labania`.
3. Upload `index.html`, `styles.css`, and `script.js` (and this README if desired) to the repository's main branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your site URL will be shown in the Pages settings.

A free GitHub Pages address is usually `https://YOUR-USERNAME.github.io/labania/`.
